### مجموعه ابزارهای حرفه‌ای کار با رنگ

---

## ✨ ویژگی‌ها

| ابزار | توضیحات |
|-------|---------|
| 🌈 **پالت رنگ** | تولید و نمایش پالت‌های رنگی زیبا |
| 🔍 **بررسی تضاد** | ابزار WCAG برای بررسی کنتراست رنگ‌ها |
| 🎯 **انتخاب رنگ** | انتخاب و تطبیق رنگ‌ها |

---

## 📁 ساختار فایل‌ها

```
📦 color/
├── 📄 index.html        ← صفحه اصلی
├── 📄 contrast.html     ← ابزار بررسی تضاد رنگ
└── 📄 palette.html      ← ابزار پالت رنگ
```

---

## 🛠 نحوه اجرا

```bash
python -m http.server 8080
# سپس باز کردن http://localhost:8080
```

یا مستقیماً فایل `index.html` را در مرورگر باز کنید.

---

## 📊 ابزار بررسی تضاد (contrast.html)

- بررسی کنتراست بین دو رنگ
- نمایش رتبه WCAG (AA/AAA)
- مناسب برای طراحی دسترس‌پذیر

## 📊 ابزار پالت رنگ (palette.html)

- تولید پالت‌های رنگی حرفه‌ای
- نمایش کدهای HEX و RGB
- امکان کپی کدهای رنگ
